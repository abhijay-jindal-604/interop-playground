# Gaps write-up (v1, 2026-10-20)

This is the list of interoperability gaps we found while researching and building Interop Playground. It covers the Inji stack (MOSIP Inji Certify, Inji Verify, Mimoto, Inji Web and the Inji libraries) and the peers we ran it against.

- **Versions.** Inji components are `1.0.0-alpha.1` unless a commit is named, eSignet is `1.8.0`, and walt.id is `1.1.0` (all pinned in [`versions.lock`](../versions.lock)).
- **Evidence** cites, in this order: a **run ID** of a run the build made, with its committed report ([`docs/reports/`](reports/)); a **repo path** that reproduces or encodes the gap (a recorded upstream answer, a test, a selector rule); or **research reproduction**, meaning we reproduced it while researching the stack and the build did not re-run it. Issue drafts will carry the same evidence plus a trimmed transcript, and they are filed upstream by hand only.
- **Status** says what the build itself did with the gap:
  - **reproduced in build**: seen again on the bundle while building (run ID or commit named).
  - **relied on**: the build encodes a rule, a workaround or a test for it (a greyed-out selector cell with the gap ID, a fingerprint, an adapter rule). The gap is not re-run as a finding.
  - **research only**: documented and reproduced in research. The submission build does not exercise it.

v1 is written on 2026-10-20 from the research and the merged build (up to commit `08b2c74`). The approved issue drafts and the URLs of filed issues come in the final version.
