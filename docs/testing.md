# Interop Playground: test cases and results

_v1, 2026-10-21. Team Bhrinjal (Abhijay Jindal, Shrey Bhardwaj, Aryan Bedwal)._

The playground has four layers of tests: fast Vitest suites that need no Docker (unit, contract, integration, repository checks and UI components), a Playwright suite against the built UI with recorded API answers, opt-in tests against the running bundle, and live Playwright specs that drive the real Inji services. This page lists the cases, the edge cases they cover, and the results.

## Results summary

The no-Docker suites were run on **2026-10-21** in a fresh clone of commit `aaffa79` (Node 22, Linux):

| Command             | What it runs                                                                                                  | Result                                                               |
| ------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `npm ci`            | install from `package-lock.json`                                                                              | 542 packages installed, exit 0                                       |
| `npm run lint`      | ESLint (with the project's own rules), the no-GitHub-write lint, the secret scan and the flow-file validation | exit 0, no findings                                                  |
| `npm run typecheck` | `tsc -b` over every workspace                                                                                 | exit 0                                                               |
| `npm test`          | Vitest, all projects (unit, contract, integration, repo, ui)                                                  | **682 passed, 8 skipped, 0 failed** (60 files: 58 passed, 2 skipped) |
| `npm run e2e`       | Playwright on the built UI with recorded API answers                                                          | **54 passed, 0 failed** (18 functional, 36 accessibility)            |

The 8 skipped tests are deliberate: 7 are the opt-in bundle tests (`BUNDLE_IT=1`, they need the running stack) and 1 checks a JSON-LD fallback that only applies when the `jsonld` library is absent.

Live results against the real Inji services are from **2026-10-20** and are cited from [`docs/evidence/`](evidence/) and [`docs/reports/`](reports/), not re-run for this page (see [Live end-to-end results](#live-end-to-end-results)).

## How to run each suite

```bash
npm ci                      # once
npm run lint                # eslint + no-GitHub-write lint + secret scan + flow validation
npm run typecheck           # tsc -b
npm test                    # every Vitest project (needs port 3100 free: run it with the bundle down)
npm run test:unit           # one project: unit | contract | integration | repo | ui
npm run e2e                 # fixture Playwright (builds the UI, serves it on 127.0.0.1:4173)
npx playwright install chromium   # once, before the live specs
npm run e2e:live            # live Playwright against scripts/up.sh --with peers
npm run e2e:live -- slice   # one live spec: slice | labels | ldp | fixit
BUNDLE_IT=1 npx vitest run apps/bff/src/main.bundle.int.test.ts   # opt-in bundle tests
npm run store:scan          # scan the run database for leaked secrets
```

Every Vitest project except `integration` and `repo` installs a network guard ([`packages/testkit/src/network-guard.test.ts`](../packages/testkit/src/network-guard.test.ts)): any request to a non-loopback host fails the test, so these suites cannot depend on the internet.

## Continuous integration

[`.github/workflows/ci.yml`](../.github/workflows/ci.yml) runs on every push and pull request with a read-only token and every action pinned by commit SHA. It has six jobs:

| Job           | Steps                                                                                                                                                          |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `static`      | `npm ci`, lint, `format:check`, typecheck, `contracts:check`, contrast, full-history secret scan, repo tests                                                   |
| `unit`        | unit tests with coverage, contract tests                                                                                                                       |
| `integration` | integration tests                                                                                                                                              |
| `sidecar`     | builds the JVM sidecar, checks for duplicate classes, runs its smoke test (SD-JWT verify true, tampered false, JSON-LD verify true)                            |
| `ui`          | UI component tests, Vite build with the bundle budget, Playwright (`npm run e2e`)                                                                              |
| `ci-fast`     | reserved for the suite runner on fakes; its run step is guarded by `ci/profiles.json`, which v1 does not ship (suites are not in v1), so the job only installs |

No CI job starts Docker stacks, talks to the Collab sandbox or opens a tunnel. The live specs run on a developer machine with the bundle up.
